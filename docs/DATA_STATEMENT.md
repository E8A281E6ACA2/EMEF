# Data statement

The complete evaluation data are withheld from this prepublication artifact
because the source paragraphs originate from a processed literature corpus and
redistribution rights have not yet been cleared.

This repository therefore contains:

- 20 original synthetic passages under `data/synthetic/samples.jsonl`;
- a synthetic gold/prediction pair under `examples/evaluation/`;

It does not contain source titles, source paths, authors, affiliations, e-mail
addresses, DOI metadata, raw evidence passages, provider endpoints, dataset-level
statistics, or paper-level experimental results. The final data release will be
governed separately after publication and rights review.
